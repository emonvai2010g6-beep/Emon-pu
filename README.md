# IslamicFunZone

বাংলা ভাষায় তৈরি একটি ফ্রি, মোবাইল-ফ্রেন্ডলি কুইজ ও গেম ওয়েবসাইটের প্রাথমিক সংস্করণ।

## ফাইল
- `index.html` — ওয়েবসাইটের কাঠামো
- `style.css` — ডিজাইন ও মোবাইল লেআউট
- `app.js` — কুইজ, গেম, স্কোর ও প্রশ্নের ডেটা

## কী আছে
- ১০টি ক্যাটাগরি এবং ১০০টি প্রশ্নের ব্যাংক
- ইসলামিক জ্ঞান, বাংলাদেশ, বিজ্ঞান, বিশ্বজ্ঞান, ইংরেজি, গণিত, প্রকৃতি, প্রযুক্তি, ইতিহাস ও সাধারণ জ্ঞান
- দ্রুত কুইজ, সত্য/মিথ্যা, ধাঁধা এবং দৈনিক চ্যালেঞ্জ
- টাইমার, উত্তর ব্যাখ্যা, স্কোর, লেভেল ও ব্যাজ
- প্রশ্ন খোঁজার সার্চ
- মোবাইল-ফ্রেন্ডলি ডিজাইন
- স্কোর `localStorage`-এ এই ডিভাইসের ব্রাউজারে সংরক্ষণ

## GitHub Pages-এ প্রকাশ
1. GitHub-এ নতুন repository তৈরি করো।
2. এই ZIP ফাইলটি Extract করো।
3. `index.html`, `style.css`, `app.js`, `README.md` ফাইলগুলো repository-র মূল ফোল্ডারে আপলোড করো।
4. Commit changes করো।
5. Repository → **Settings** → **Pages**-এ যাও।
6. Build and deployment অংশে **Deploy from a branch**, branch `main`, folder `/(root)` বেছে **Save** চাপো।
7. প্রকাশ হলে GitHub Pages-এর দেওয়া লিংক খোলো।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
GitHub Pages স্ট্যাটিক হোস্টিং। এই সংস্করণে কোনো সার্ভার বা Firebase নেই। স্কোর শুধু একই ব্রাউজার/ডিভাইসে থাকে; অন্য ব্যবহারকারীর স্কোর দেখা, নিরাপদ অ্যাকাউন্ট, ক্লাউড সেভ বা লাইভ মাল্টিপ্লেয়ার নেই। এসব ফিচারের জন্য আলাদা ব্যাকএন্ড লাগবে।

ইসলামিক প্রশ্নগুলো শিক্ষামূলক সাধারণ তথ্য হিসেবে দেওয়া হয়েছে। গুরুত্বপূর্ণ ধর্মীয় বিষয়ে নির্ভরযোগ্য উৎস দিয়ে যাচাই করে নাও।
